## Принятые решения

- ТЗ определяет спортивную предметную область; `cyber.zip` определяет визуальный язык.
- EagleCode и тёмная cyber-тема сохраняются.
- Mock API хранит изменения в `localStorage` и заменяется HTTP-адаптером без изменений UI.
- Уровни рассчитываются централизованно, рейтинг сортируется по метрам.
- Проверяются только необходимые пользовательские поля; без избыточной нормализации данных.
