# Модуль проведения контестов (Кейс №2)

Сценарий кейса: организатор создаёт контест → добавляет задания → публикует → спортсмен отправляет решение → организатор проверяет → итоговая таблица → результат в профиле и рейтинге.

## Принятые решения
- Контест — это `Competition` с `format=contest`: результаты, профиль и рейтинг переиспользуются без изменений.
- Жизненный цикл: `draft` (Черновик) → `registration` (Опубликован) → `active` (Идёт) → `finished` (Завершён); вручную из кабинета и автоматически по времени.
- Баллы IOI: балл задачи = максимум × доля пройденных тестов, берётся лучшая попытка; ручная оценка организатора переопределяет автоматическую.
- Места: сумма баллов ↓, затем время последнего улучшения ↑; полное равенство — общее место.
- Метры за контест: `reward × набранные / максимальные баллы`.
- Judge — одноразовый контейнер без сети с лимитами CPU/RAM/pids; код и тесты передаются через stdin.
