## Принятые решения

- React остаётся в корне, backend расположен в `backend/`.
- PostgreSQL используется в runtime; SQLite разрешён только для быстрых локальных тестов.
- Рейтинг хранится как баланс и изменяется только через неизменяемый журнал операций.
- Верхняя граница уровня вычисляется из следующего порога.
- API возвращает camelCase и непагинированные массивы для совместимости с текущим frontend.
- Уведомления синхронные и внутрисистемные; файловые загрузки и фоновые очереди не используются.
